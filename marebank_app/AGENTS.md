# AGENTS.md

## Contexto do projeto

Este repositório é uma aplicação frontend do MaréBank, com dados persistidos localmente no navegador.

## Arquivos-chave

- `src/`: código da aplicação.
- `src/api/localClient.js`: cliente local da app.
- `src/lib/local-data.js`: armazenamento e dados iniciais locais.
- `vite.config.js`: configuração do Vite.

## Observações

- Prefira manter a aplicação autônoma e sem integrações externas.
- Use `npm run dev` para rodar o frontend localmente.
- Valide os ajustes com os checks do projeto antes de concluir.
